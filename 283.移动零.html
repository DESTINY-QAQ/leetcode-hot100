283. 移动零

将所有 0 移动到数组末尾，同时保持非零元素的相对顺序，并且必须原地修改数组。

数组双指针原地算法

查看 LeetCode 原题

我的代码记录

先把非零元素按原顺序覆盖到数组前部，再将剩余位置统一补零。

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)
        count = 0

        for i in range(n):
            if nums[i] != 0:
                nums[count] = nums[i]
                count += 1

        for i in range(count, n):
            nums[i] = 0

        print(nums)
曾经的错误：nums.sort() 会改变非零元素的相对顺序，不符合题目要求。例如 [0, 2, 1] 应变为 [2, 1, 0]，而不是 [0, 1, 2]。

提交时应删除 print(nums)：题目要求原地修改，不需要输出或返回结果。

方法一解析：覆盖后补零

  1. count 表示下一个非零元素应该写入的位置。
  2. 从左到右扫描；遇到非零数，就写入 nums[count]，然后将 count 加一。
  3. 扫描结束后，区间 [0, count) 已包含全部非零元素，且顺序不变。
  4. 将区间 [count, n) 全部置零。
时间复杂度 O(n)数组最多被线性遍历两次。
空间复杂度 O(1)只使用常数个额外变量。

整理后的提交版本

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        write = 0

        for num in nums:
            if num != 0:
                nums[write] = num
                write += 1

        for i in range(write, len(nums)):
            nums[i] = 0

方法二：双指针交换

left 指向下一个应放置非零元素的位置，right 负责扫描数组。发现非零元素时，将它与 left 位置交换。

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        left = 0

        for right in range(len(nums)):
            if nums[right] != 0:
                if left != right:
                    nums[left], nums[right] = nums[right], nums[left]
                left += 1

与基础双指针写法相比，left != right 的判断避免了数组前部本来就是非零元素时的无意义自交换。该方法只扫描一次，也保持非零元素的相对顺序。

时间复杂度 O(n)right 只从左向右移动一次。
空间复杂度 O(1)交换直接发生在原数组中。

如何选择？

  • 覆盖后补零：逻辑直观、容易证明正确；每个非零元素先紧凑排列，再统一补零。
  • 双指针交换：一次遍历即可完成，过程更贴合“把 0 向后移动”的直觉。
  • 推荐：面试时优先写优化后的双指针交换法，并清楚说明两个指针各自维护的含义。

示例推演

输入 [0, 1, 0, 3, 12]，非零元素依次被放到下标 0、1、2，最终得到 [1, 3, 12, 0, 0]。
