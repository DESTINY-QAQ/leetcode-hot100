11. 盛最多水的容器

选择两条竖线作为容器边界，在不能倾斜容器的条件下，求它能够容纳的最大水量。

数组双指针贪心

查看 LeetCode 原题

我的代码记录

左右指针从数组两端开始，计算当前容器面积，然后移动较矮一侧的指针，直到两个指针相遇。

class Solution:
    def maxArea(self, height: List[int]) -> int:
        # 思路：双指针
        n = len(height)
        left = 0
        right = n - 1
        ans = 0

        while left < right:
            ans = max(
                ans,
                min(height[left], height[right]) * (right - left)
            )

            if height[left] <= height[right]:
                left += 1
            else:
                right -= 1

        return ans
代码结论：写法正确。两侧等高时移动任意一侧都不会漏掉最优解，所以使用 <= 移动左指针没有问题。

核心公式

下标 left 和 right 组成的容器，其宽度和有效高度分别为：

width = right - left
effective_height = min(height[left], height[right])
area = width * effective_height

容器的水面由较矮的竖线限制。中间柱子的高度不影响结果，这一点与“接雨水”按列累加的模型不同。

宽度由两条竖线的横坐标差决定。
有效高度由左右边界中较矮的一条决定。

为什么移动较矮的一侧？

假设当前有 height[left] ≤ height[right]，此时面积受左侧高度限制。

  1. 如果保留 left，只把 right 向左移动，宽度一定变小。
  2. 新容器的有效高度最多仍是 height[left]，不可能超过当前短板。
  3. 因此所有仍使用当前 left、但右边界更靠左的容器，都不可能超过当前面积。
  4. 可以安全排除当前左边界，令 left += 1，寻找更高的短板。

当右侧更矮时完全对称，移动 right。每一步都排除一个不可能产生更优答案的边界。

时间复杂度 O(n)两个指针总共移动 n−1 次。
空间复杂度 O(1)只使用指针和答案等常数个变量。

整理后的提交版本

class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        max_area = 0

        while left < right:
            width = right - left
            current_height = min(height[left], height[right])
            max_area = max(max_area, width * current_height)

            if height[left] <= height[right]:
                left += 1
            else:
                right -= 1

        return max_area

示例推演

输入 [1, 8, 6, 2, 5, 4, 8, 3, 7]。最优边界是下标 1 和 8，宽度为 7，有效高度为 min(8, 7) = 7，最大面积为 7 × 7 = 49。

  • 不能移动更高一侧：宽度变小的同时，限制面积的短板仍然存在，不可能得到更大面积。
  • 不要累加每一列：题目只要求选定两条边界后的矩形面积。
  • 边界安全：题目保证数组长度至少为 2，循环至少能够计算一次面积。
