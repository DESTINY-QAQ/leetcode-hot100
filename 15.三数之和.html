15. 三数之和

在整数数组中找出所有和为 0 的三元组，并保证返回结果中不包含重复三元组。

数组排序双指针剪枝去重

查看 LeetCode 原题

我的代码记录

先排序，再固定第一个数 x；剩余两个数通过左右指针寻找，同时利用有序性进行剪枝和去重。

class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        ans = []
        n = len(nums) - 1

        for i in range(n - 1):
            x = nums[i]

            if i > 0 and x == nums[i - 1]:
                continue

            if x + nums[i + 1] + nums[i + 2] > 0:
                break

            if x + nums[-2] + nums[-1] < 0:
                continue

            j = i + 1
            k = n

            while j < k:
                s = x + nums[j] + nums[k]

                if s > 0:
                    k -= 1
                elif s < 0:
                    j += 1
                else:
                    if j == i + 1 or nums[j] != nums[j - 1]:
                        ans.append([x, nums[j], nums[k]])
                    j += 1
                    k -= 1

        return ans
代码结论：这段实现是正确的。变量 n 实际保存的是“最后一个下标”而不是数组长度；不影响结果，但改名为 last，或者让 n = len(nums)，会更容易阅读。

排序 + 固定一个数 + 双指针

  1. 排序后，三元组天然按照从小到大的顺序产生，便于移动指针和去重。
  2. 枚举下标 i，固定第一个数 x = nums[i]。
  3. 令 j = i + 1、k = n - 1，在右侧区间寻找另外两个数。
  4. 如果总和小于 0，需要增大总和，因此右移 j。
  5. 如果总和大于 0，需要减小总和，因此左移 k。
  6. 总和等于 0 时记录答案，并同时收缩左右指针。
时间复杂度 O(n²)固定一个数需要 O(n)，每轮双指针扫描需要 O(n)。
额外空间 O(1)不计排序内部开销和返回答案所占空间。

排序本身需要 O(n log n)，但被后续的 O(n²) 双指针过程覆盖，因此总时间仍为 O(n²)。

两处剪枝为什么成立？

最小和大于 0：直接结束

if x + nums[i + 1] + nums[i + 2] > 0:
    break

这是当前 x 能组成的最小三数和。如果它已经大于 0，当前下标不可能找到答案；后续固定的 x 只会更大，所以可以结束整个外层循环。

最大和小于 0：跳过当前数

if x + nums[-2] + nums[-1] < 0:
    continue

这是当前 x 能组成的最大三数和。如果连它都小于 0，那么当前 x 无解，但更大的下一个 x 仍可能有解，因此只能 continue，不能 break。

去重逻辑

  • 固定数去重：nums[i] == nums[i - 1] 时跳过，避免针对同一个值重复搜索。
  • 你的内层去重：只在找到答案时检查 nums[j] 是否与前一个值相同。固定 x 后，一个确定的第二个值只能对应一个第三个值，因此足以避免重复输出。
  • 更常见的写法：找到答案后，同时跳过左右两侧所有相同值。逻辑更对称，也能减少无意义比较。
去重对象是数值组合，不是下标组合。例如三个不同下标可能都包含相同的数值，但答案中 [-1, 0, 1] 只能出现一次。

整理后的提交版本

class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        n = len(nums)
        ans = []

        for i in range(n - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            if nums[i] + nums[i + 1] + nums[i + 2] > 0:
                break

            if nums[i] + nums[n - 2] + nums[n - 1] < 0:
                continue

            left, right = i + 1, n - 1

            while left < right:
                total = nums[i] + nums[left] + nums[right]

                if total < 0:
                    left += 1
                elif total > 0:
                    right -= 1
                else:
                    ans.append([nums[i], nums[left], nums[right]])
                    left += 1
                    right -= 1

                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1

        return ans

示例推演

[-1, 0, 1, 2, -1, -4] 排序后为 [-4, -1, -1, 0, 1, 2]。固定 -1 时，双指针依次找到 [-1, -1, 2] 和 [-1, 0, 1]；下一个重复的 -1 会被外层去重跳过。

  • 不要忘记排序：指针移动方向、剪枝和相邻去重都建立在数组有序的基础上。
  • 不要用集合掩盖重复：正确的指针去重能直接避免生成重复答案。
  • 注意原数组被修改：nums.sort() 会原地改变输入顺序；本题允许这样做。
