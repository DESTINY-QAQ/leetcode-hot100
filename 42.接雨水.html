42. 接雨水

给定一组宽度均为 1 的非负柱子，计算下雨后这些柱子之间能够接住的雨水总量。

数组前后缀最大值双指针

查看 LeetCode 原题

我的代码记录

分别预处理每个位置左边和右边的最高柱子，再逐列计算这一位置能够存放的水量。

class Solution:
    def trap(self, height: List[int]) -> int:
        # 每一列的水量：min(前缀最大值, 后缀最大值) - 当前高度
        n = len(height)
        ans = 0

        # 前缀最大值序列
        l1 = [0] * n
        l1[0] = height[0]
        for i in range(1, n):
            l1[i] = max(height[i], l1[i - 1])

        # 后缀最大值序列
        l2 = [0] * n
        l2[-1] = height[-1]
        for i in range(-2, -n - 1, -1):
            l2[i] = max(height[i], l2[i + 1])

        for i in range(n):
            ans += min(l1[i], l2[i]) - height[i]

        return ans
结论先行：这段负下标循环没有错误。range(-2, -n - 1, -1) 会依次产生 -2, -3, ..., -n，刚好从倒数第二个元素处理到第一个元素。

题目保证 n ≥ 1，因此对 l1[0]、l2[-1] 和 height[0] 的访问都是安全的。

核心公式：按列计算

位置 i 能达到的水面高度，取决于它左边最高柱子和右边最高柱子中较矮的一个：

water[i] = min(left_max[i], right_max[i]) - height[i]
  1. left_max[i] 表示区间 [0, i] 内的最大高度。
  2. right_max[i] 表示区间 [i, n - 1] 内的最大高度。
  3. 较矮的边界决定水面上限，再减去当前柱高，就是这一列的水量。

两个最大值都包含当前位置，因此公式结果一定不会为负数；最左端和最右端也会自然贡献 0。

方法一解析：前后缀最大值

你的实现逻辑完整。为了让下标方向更容易阅读，可以将后缀循环改成常规正下标：

class Solution:
    def trap(self, height: List[int]) -> int:
        n = len(height)
        left_max = [0] * n
        right_max = [0] * n

        left_max[0] = height[0]
        for i in range(1, n):
            left_max[i] = max(left_max[i - 1], height[i])

        right_max[-1] = height[-1]
        for i in range(n - 2, -1, -1):
            right_max[i] = max(right_max[i + 1], height[i])

        water = 0
        for i in range(n):
            water += min(left_max[i], right_max[i]) - height[i]

        return water
时间复杂度 O(n)构造两个数组并求和，共进行三次线性遍历。
空间复杂度 O(n)两个长度为 n 的辅助数组仍属于 O(n) 空间。

负下标版本与正下标版本在正确性和复杂度上没有区别；正下标只是更符合多数人的阅读习惯。

方法二：双指针优化空间

前后缀数组保存了所有位置的最大值，但计算当前位置时只需要当前的 left_max 和 right_max。因此可以用左右指针把额外空间降到常数级。

class Solution:
    def trap(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        left_max = height[left]
        right_max = height[right]
        water = 0

        while left < right:
            if left_max <= right_max:
                left += 1
                left_max = max(left_max, height[left])
                water += left_max - height[left]
            else:
                right -= 1
                right_max = max(right_max, height[right])
                water += right_max - height[right]

        return water
为什么可以移动较矮的一侧？当 left_max ≤ right_max 时，左侧当前位置的水量已经由 left_max 决定；右边至少存在一个高度为 right_max 的边界，不必再知道更靠内的具体高度。另一侧同理。
时间复杂度 O(n)左右指针合计只移动 n−1 次。
空间复杂度 O(1)只保留两个指针、两个最大值和答案。

示例推演与易错点

height = [4, 2, 0, 3, 2, 5]

每个位置的积水量依次为 [0, 2, 4, 1, 2, 0]，总量为 9。

  • 不能只看相邻柱子：决定水量的是当前位置两侧的最高边界，而不是左右相邻高度。
  • 不要把两侧最大值相加：水面受短板限制，所以必须使用 min(left_max, right_max)。
  • 区分时间和空间：前后缀方案已经是 O(n) 时间，但仍使用 O(n) 额外空间；双指针优化的是空间。
